# Входные данные для примеров

В репозитории нет искусственного «метеонаблюдения», выдаваемого за настоящую сцену. Для повторения карт использовать собственные GeoTIFF с проверяемым происхождением. Для профилей заполнить схему из docs/SCIENCE.md реальными значениями, их единицами, временем и источником.

Маршрут вводится как строки longitude, latitude или GeoJSON LineString. Это геометрия, не рекомендация безопасного пути.

Тестовые массивы создаются только в tests/test_science.py, содержат метку SYNTHETIC UNIT TEST ONLY и удаляются после проверки. Они не используются для оценки метеорологической результативности.
