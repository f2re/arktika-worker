# Контекстный интерфейс 0.3.0: карта, мультислойность и источники

## 1. Концепция и визуальная система

Интерфейс рабочей станции спроектирован по принципу **контекстного минимализма**: рабочая карта остаётся центральным элементом, а специализированные панели управления и аналитические инструменты раскрываются по требованию.

### Ключевые архитектурные решения:
- **Полная автономность**: Реализовано на чистом стеке HTML5, современном CSS (Custom Properties, Flexbox, Grid) и модульном JavaScript (ES6). Отсутствуют сторонние фреймворки (React, Vue, MUI), Node.js в рантайме и внешние CDN. Интерфейс гарантированно функционирует в изолированных закрытых сетях без доступа в Интернет.
- **Векторная графика**: Все пиктограммы нарисованы специально для проекта и встроены в виде легковесных SVG-примитивов. Внешние файлы шрифтов не загружаются — используются быстрые системные шрифты ОС (`system-ui`, `-apple-system`, `Segoe UI`, `Roboto`).
- **Строгая цветовая дисциплина**: Системные акцентные цвета (синий/индиго) применяются только для элементов управления и фокуса. Цветовые палитры метеорологических растров, RGB-композиций и категориальных фазовых карт изолированы от темы интерфейса и строго соответствуют физическим шкалам.

## 2. Структура экранов и навигация

Интерфейс разделен на четыре согласованные зоны:

```text
┌────────────────────────────────────────────────────────────────────────┐
│ ВЕРХНЯЯ ПАНЕЛЬ: Дата | Аппарат | Пресет карты | Продукт/Канал | Действия │
├──────┬───────────────────────────────────────────────────┬─────────────┤
│      │                                                   │             │
│ Р    │                                                   │ ПРАВЫЙ      │
│ Е    │                                                   │ ИНСПЕКТОР:  │
│ Й    │            ИНТЕРАКТИВНАЯ КАРТА                    │             │
│ Л    │   (спутниковый растр + слои реанализа             │ • Точка     │
│      │    + береговая линия + изолинии + маршрут)        │ • Профиль   │
│ К    │                                                   │ • Маршрут   │
│ Н    │                                                   │ • Анализ    │
│ О    │                                                   │             │
│ П    │                                                   │             │
│ О    │                                                   │             │
│ К    │                                                   │             │
├──────┴───────────────────────────────────────────────────┴─────────────┤
│ НИЖНЯЯ ЛЕНТА: Хронология доступных сеансов съёмки выбранного дня        │
└────────────────────────────────────────────────────────────────────────┘
```

1. **Верхняя панель быстрого доступа**:
   - Выбор даты и оперативного диапазона.
   - Переключение космического аппарата («Арктика-М» №1 / №2).
   - Выбор географического пресета карты (Арктика, Евразия, Атлантика и др.).
   - Меню спектральных продуктов и каналов МСУ-ГС.
   - Кнопки вызова модальных окон: «Источники данных», «Слои реанализа», «Калибровка», «Справка».

2. **Боковой рейл кнопок**: Компактные быстрые действия (сброс масштаба, центрирование, включение маски геометрической ночи, очистка маршрута).

3. **Центральный интерактивный холст**:
   - Плавное панорамирование (drag & drop) и зумирование колесом мыши относительно позиции курсора.
   - Поддержка горячих клавиш: `+` / `-` для масштаба, `0` для сброса вида, стрелки для перемещения.
   - Мультислойный рендеринг: базовый спутниковый растр + до 8 накладываемых слоев реанализа с раздельной регулировкой прозрачности.

4. **Правый инспектор (контекстные вкладки)**:
   - **Анализ точки**: По щелчку на карте отображаются яркостные температуры всех каналов, спектральные разности, физические гипотезы и рекомендации.
   - **Профиль**: Отображение высотного хода температуры $T(z)$, точки пересечения с $T_я$ облака, расчёт ВГО и интегральных влагозапасов.
   - **Маршрут**: Интерактивное построение полётного трека кликами по карте, редактирование узлов, расчёт времени пролёта ETA и метеоусловий.

5. **Нижняя хронологическая лента**: Горизонтальный список сеансов съёмки за выбранный день с визуальной индикацией комплектности каналов на диске.

## 3. Модальные окна и рабочие сценарии (0.3.0)

### 3.1. Интерактивный Центр справки (`#helpDialog`)
Полноценный встроенный справочник с тематическими вкладками:
- 🚀 **Быстрый старт**: 4 простых шага от запуска сервера до экспорта геопродукта.
- 🔑 **Где взять токен**: Пошаговые иллюстрированные инструкции по получению токенов через DevTools F12 для GPTL, а также для Copernicus CDS и NASA Earthdata.
- 🛰️ **Каналы МСУ-ГС**: Таблица спектральных диапазонов, центральных длин волн и физического назначения каналов 1–10.
- 🎨 **Продукты и RGB**: Физический смысл композиций (микрофизика, контраст пыли, контраст пепла), правила интерпретации цветов и предупреждения.
- 🛠️ **Инструменты**: Руководство по калибровке, анализу профиля, расчёту высоты ВГО и прокладке авиационных маршрутов.

### 3.2. Центр источников данных (`#sourcesDialog`)
Единый экран управления доступом к геопорталу GPTL, Copernicus CDS (ERA5, CARRA2) и NASA Earthdata (MERRA-2). Предоставляет прямые ссылки на генерацию токенов и индикаторы статуса подключения.

### 3.3. Панель полей реанализа и мультислойности (`#reanalysisDialog`)
- Каталог полей с фильтрацией по источникам, переменным и уровням.
- Стек активных слоёв с ползунками прозрачности (0–100%).
- Переключение стилей визуализации: сплошная заливка (`fill`), изолинии (`contours`), комбинированный режим, векторные стрелки ветра (`arrows`).
- Мастер разностных полей ($A - B$) для пространственного сопоставления моделей между собой.

## 4. Доступность (A11y) и адаптивность

- **Клавиатурная навигация**: Полная поддержка стандарта WAI-ARIA Dialog и Tooltip Patterns. Модальные окна захватывают фокус при открытии и закрываются по клавише `Escape`.
- **Подсказки и контраст**: Все кнопки содержат понятные атрибуты `aria-label` и высококонтрастные всплывающие подсказки.
- **Поддержка медиа-запросов**: Поддерживается системная настройка `prefers-reduced-motion` для пользователей, чувствительных к анимациям.
- **Адаптивные размеры**: Макет верифицирован на настольных разрешениях от 1920×1080 до 1024×768, а также в мобильном режиме 390×844 с наложением панелей поверх карты по одной.
