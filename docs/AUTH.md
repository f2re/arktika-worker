# 🔑 Авторизация и подключение источников данных

Руководство по получению и настройке ключей доступа для работы со спутниковыми снимками «Арктика-М» и метеорологическими реанализами (ERA5, CARRA2, MERRA-2).

> [!NOTE]
> **Принцип безопасности:** все токены и пароли хранятся **исключительно в оперативной памяти** работающего Python-сервера. Они **никогда не сохраняются на диск**, не попадают в базу данных SQLite, в браузерный `localStorage`, в файлы конфигурации или в логи. При закрытии сервера все реквизиты мгновенно и бесследно уничтожаются.

---

## 🛰️ 1. Геопортал Роскосмоса (GPTL / «Арктика-М»)

Токен доступа (JWT Bearer) необходим для **поиска в каталоге** и **скачивания новых снимков** с серверов Роскосмоса (GPTL).

> [!TIP]
> **Если у вас уже есть скачанные GeoTIFF-файлы** на диске, токен **не требуется**! Просто нажмите **«Открыть GeoTIFF»** в панели снимков и укажите локальную папку.

### 📋 Пошаговый способ копирования токена из браузера (самый быстрый):

1. **Войдите на портал**: откройте в браузере [geoportal.gptl.ru](https://geoportal.gptl.ru/) и авторизуйтесь под своей учётной записью.
2. **Откройте панель разработчика (DevTools)**:
   * Нажмите клавишу `F12` (или `Ctrl + Shift + I` в Windows/Linux, `Cmd + Option + I` на macOS).
   * Перейдите на вкладку **«Сеть» (Network)**.
3. **Отфильтруйте запросы**:
   * В строке фильтра выберите тип **Fetch/XHR**.
   * Обновите страницу или кликните по любому разделу каталога/карты на портале.
4. **Найдите сетевой запрос**:
   * В списке запросов кликните по любому обращению к API (например, к `api.gptl.ru`, запросы `search`, `catalogs`, `profile`, `user` и т.д.).
5. **Скопируйте токен**:
   * В правой части окна откройте вкладку **«Заголовки» (Headers)**.
   * Прокрутите до блока **«Заголовки запроса» (Request Headers)**.
   * Найдите заголовок `Authorization: Bearer eyJ...`.
   * Скопируйте длинную строку токена (начинается с `eyJ...`). Можно скопировать как чистый токен, так и вместе со словом `Bearer ` — приложение поймёт оба варианта!
6. **Вставьте токен в «Арктика-М»**:
   * В верхнем правом углу рабочего места нажмите кнопку с ключом **🔑 (Источники данных)**.
   * На карточке **«Арктика-М / GPTL»** нажмите кнопку **«Подключение»**.
   * Вставьте скопированный токен в поле **«Bearer / access token»** и нажмите **«Подключить»**.
   * Индикатор покажет оставшееся время жизни токена (например, *«Bearer: 54 мин»*).

### 🔄 Режим зарегистрированного OAuth-клиента

Если у вашей организации есть зарегистрированный оператором GPTL OAuth `client_id`:
1. Укажите точный `redirect_uri` (по умолчанию `http://127.0.0.1:8765/oauth/callback`).
2. В окне подключения разверните блок **«Получение и обновление через OAuth»**, укажите ваш `client_id` и нажмите **«Сохранить параметры»**.
3. Нажмите **«Войти через GPTL»** — произойдет защищённая авторизация по стандарту OAuth 2.0 PKCE (S256).
4. Токены доступа и обновления сохранятся в памяти, и приложение сможет обновлять access token автоматически до окончания сессии.

## 🌍 2. Copernicus CDS (ERA5 и CARRA2)

Нужен для загрузки пространственных полей атмосферного реанализа **ERA5** и регионального арктического реанализа **CARRA2**, а также для экспериментального автоматического подбора температурных шкал.

1. **Регистрация**: создайте учётную запись на [cds.climate.copernicus.eu](https://cds.climate.copernicus.eu/).
2. **Лицензии**: откройте страницу набора данных [ERA5 hourly pressure levels](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-pressure-levels) и внизу вкладки «Download» примите условия использования (Terms of Use) — это делается один раз.
3. **Получение токена**:
   * Перейдите на страницу инструкции [How to use the CDS API](https://cds.climate.copernicus.eu/how-to-api) (или в свой профиль).
   * Скопируйте **Personal Access Token (PAT)** — строку вида `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`.
4. **Подключение**:
   * В приложении: кнопка **🔑** ➔ **Copernicus CDS** ➔ **«Подключение»**.
   * Вставьте токен в поле или нажмите **«Выбрать файл доступа»** (поддерживаются файлы `.cdsapirc` и `.netrc`).
   * Нажмите **«Сохранить в памяти»**.

## 🚀 3. NASA Earthdata (MERRA-2)

Нужен для загрузки данных глобального атмосферного реанализа **MERRA-2** через центр NASA GES DISC.

1. **Регистрация**: зарегистрируйтесь на портале [urs.earthdata.nasa.gov](https://urs.earthdata.nasa.gov/).
2. **Разрешение доступа (Authorized Apps)**:
   * В личном кабинете перейдите в раздел **«Applications»** ➔ **«Authorized Apps»**.
   * Убедитесь, что приложение **«NASA GES DISC DATA ARCHIVE»** добавлено в список разрешённых (при необходимости найдите через «Approve More Applications»).
3. **Получение токена**:
   * В меню **«Applications»** перейдите в **«Generate Token»**.
   * Скопируйте полученный **User Token** (Bearer token).
4. **Подключение**:
   * В приложении: кнопка **🔑** ➔ **NASA Earthdata** ➔ **«Подключение»**.
   * Вставьте токен или выберите файл `.netrc` с записью для машины `urs.earthdata.nasa.gov`.
   * Нажмите **«Сохранить в памяти»**.

## 🛡️ Безопасность и хранение секретов

* 🔒 **Только оперативная память**: секреты никогда не записываются в SQLite, `localStorage`, файлы журнала или дампы.
* 🧹 **Быстрая очистка**: в любой момент можно нажать **«Удалить токены»** в диалоге подключения, чтобы мгновенно стереть реквизиты.
* 🚫 **Защита от передачи**: приложение проверяет заголовки Host, Origin и SameSite-cookie. Ключ в URL браузера после решётки `#...` связывает интерфейс только с локальным сервером и не передаётся на внешние серверы.
