# Публикация поставки в GitHub

Репозиторий проекта: https://github.com/f2re/arktika-worker

Поставка не выполняет скрытых удалённых действий. Скрипт использует стандартную авторизацию Git, настроенную на рабочей станции пользователя (SSH-ключи или Git Credential Manager) — передавать персональные токены или пароли в чат или скрипты категорически запрещено.

---

## 1. Автоматическая подготовка ветки и публикация

Из папки проекта выполните:

```bash
python scripts/publish.py --checkout ../arktika-worker-git --push
```

На Windows:

```bat
py -3 scripts\publish.py --checkout ..\arktika-worker-git --push
```

### Что делает скрипт:
1. Клонирует репозиторий в отдельный изолированный целевой каталог `--checkout`.
2. Проверяет манифест поставки `MANIFEST.json` на целостность всех файлов.
3. Создаёт чистую тематическую ветку `feature/meteo-workstation-v0.3.0` от актуального состояния `origin/main`.
4. Переносит только отслеживаемые файлы проекта (без временных файлов, кэшей, SQLite и GeoTIFF).
5. Формирует коммит с проверенными изменениями.
6. При наличии флага `--push` отправляет ветку в удалённый репозиторий `origin` и выводит ссылку для создания Pull Request.

---

## 2. Ручная публикация без флага `--push`

Если вы хотите предварительно проверить изменения в ветке локально:

```bash
python scripts/publish.py --checkout ../arktika-worker-git
```

После проверки вы сможете отправить подготовленную ветку стандартной командой Git:

```bash
git -C ../arktika-worker-git push -u origin feature/meteo-workstation-v0.3.0
```

---

## 3. Политика безопасности манифеста

Манифест поставки (`MANIFEST.json`) строго контролирует состав файлов:
- **ВКЛЮЧЕНЫ**: Исходный код Python, модули JavaScript, CSS-стили, HTML-шаблоны, документация, тесты и открытая береговая векторная подложка Natural Earth.
- **ИСКЛЮЧЕНЫ**: Реальные спутниковые GeoTIFF, локальные файлы баз данных SQLite, файлы сессий, конфиденциальные `.env` файлы, персональные токены доступа к API, приватные URI и временные растровые кэши.
