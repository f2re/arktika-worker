# Проверка 0.2.2

## Локальная проверка, 24.09.2026

158 автоматических тестов Python завершились успешно. Проверены синтаксис Python 3.10, исходные API-контракты, арифметика, калибровочные барьеры, профили, геодезия, HTTP-ошибки, авторизация, запись/возобновление файлов и 32 новых регрессионных случая. Точный список — `tests/`.

14 браузерных проверок Chromium завершились без ошибок JavaScript: импорт локального сеанса, DN, легенда, допущение калибровки, RGB, исходный пиксель, экспорт, секунды профиля, маршрут/очистка, смена даты и быстрые переключения, размеры 1024 и 390 px. Использован `scripts/browser_smoke.py`.

В локальной среде прямой переход Chromium на localhost блокируется политикой `ERR_BLOCKED_BY_ADMINISTRATOR`. Поэтому локальный браузерный прогон использует явный `--bridge` к тому же HTTP-серверу; браузерные cookies и Origin этим режимом не проверяются. Отдельные HTTP-тесты проверяют ограничения Origin/Host/session. В GitHub Actions браузерный сценарий запускается без адаптера, на настоящем localhost.

Синтетические тестовые массивы и профили используются только как технические фикстуры. Они не выдаются за наблюдения и не подтверждают физическую точность.

## Реальные наблюдения

Для отдельного локального прогона доступны семь пользовательских L2IR GeoTIFF ARCM2 за 21.09.2026 02:00. Проверка включает чтение, продукт, пиксель и маршрут. Исходные растры и их производные не включаются в публичный репозиторий. Интерпретация DN=K в таком прогоне не подтверждает шкалу поставщика.

## Удалённые проверки

Конфигурация `.github/workflows/tests.yml` запускает Python 3.11/3.12 на Linux, Windows и macOS, а также браузерный сценарий на Linux. Факт выполнения и результат для конкретного коммита устанавливаются по GitHub Actions, а не по наличию YAML. Журналы и браузерные изображения сохраняются как артефакты CI.

## Не подтверждено техническими тестами

Живой OAuth зарегистрированного клиента и право чтения закрытых объектов GPTL; абсолютная радиометрия/межканальное совмещение; точность облачной классификации и ВГО; метеорологическая вероятность ПМЦ; интенсивность обледенения; гарантии безопасности маршрута. Эти проверки требуют независимых наблюдений и отдельной программы приёмки.
