# Каталог снимков

Выберите дату кнопкой в верхней панели. В каталоге рядом со сроком видны все десять каналов: заполненный значок — файл зарегистрирован на диске, контур — найден в каталоге, пунктир — нет найденного файла. Очередь и ошибки обозначены отдельно. «Не найден» относится к загруженному каталогу, а не ко всему архиву поставщика.

## Открыть продукт

Выберите задачу. Для отдельного канала укажите его номер. Комплектность пересчитывается сразу: например, для микрофизики нужны каналы 7, 9 и 10. Если они уже на диске, нажмите «Открыть». Профиль атмосферы для просмотра снимка не нужен.

Если комплект доступен только в каталоге, кнопка «Скачать и открыть» добавляет недостающие файлы в очередь. По завершении регистрации каналов продукт открывается автоматически. Смена даты, задачи, поиска или открытого продукта отменяет автоматическое открытие; уже заказанные файлы остаются в очереди. Для больших наборов от 512 МиБ запрашивается подтверждение.

Если части каналов нет, показаны их номера. «Скачать доступные» загружает только найденную часть и не выдаёт её за полный комплект. «Все ИК-каналы» и «Все каналы» — наборы файлов, а не новые способы цветосинтеза.

## Поиск и список файлов

Поиск работает по времени, аппарату, имени файла, уровню обработки и названиям каналов. Фильтр «На диске» показывает сроки, где готов именно выбранный набор, а не любой один канал. Фильтр «Скачать» оставляет сроки с файлами, которые можно добавить в очередь; «Ошибки» — сроки, требующие внимания.

Кнопка «Файлы» открывает список конкретного срока. У локального срока без записей загрузчика она называется «Каналы»: здесь показаны зарегистрированные исходные файлы, без предложения скачивать их повторно. Сначала показаны номер, назначение канала, проекция и размер; техническое имя файла раскрывается отдельно. «Набор по задаче» выбирает по одному варианту каждого недостающего канала. Предпочтение — EPSG:4326. Вариант, уже находящийся в очереди, повторно не загружается даже при наличии другой проекции.

Поиск внутри списка не снимает сделанный выбор. Если выбранные строки скрыты фильтром, их число явно указано у кнопки скачивания. Смена категории снимает выбор. Для другого варианта проекции можно выбрать конкретный файл вручную.

## Когда данных недостаточно

Запись без URI не исчезает: она показана как запись без ссылок на файлы. Пустой непроверенный каталог отличается от завершённого запроса без доступных файлов. Статус скачивания не доказывает доступ к объекту: он проверяется при обращении к поставщику.

Если файл удалён с диска, его канал больше не отмечается локальным. Завершённую загрузку с отсутствующим файлом можно заказать снова. Если файл существует, но не зарегистрирован как числовой канал, это показано отдельно: проверьте формат, геопривязку и имя файла.

## Физический смысл

Комплектность — наличие каналов, а не подтверждение калибровки. Режим DN, коэффициенты, исследовательское допущение DN=K и ограничения спектральных продуктов не изменены этим обновлением. Наличие файлов не превращает цветосинтез в подтверждённое опасное явление или прогноз.
