ERA5 → опорный сигнал → температурная шкала

Приложение получает атмосферу и поверхность ERA5 для выбранного спутникового срока, рассчитывает ожидаемый сигнал через установленный RTTOV 13.2 и сопоставляет его с исходными DN. Коэффициенты определяются отдельно для каждого ИК-канала. Исходные снимки не меняются.

Используется спектральный аналог другого прибора. МСУ-ГС «Электро-Л» №2 не является МСУ-ГС/А «Арктики». Набор RTTOV и опубликованные спектральные функции — не готовые коэффициенты DN→K Арктики. Результат всегда исследовательский; модельное расхождение не равно полной погрешности калибровки.

Один запуск вместо ручной подготовки

  1. Выберите архивный срок и нужный продукт. В «Температурной шкале» нажмите «Подготовить автоматически по ERA5».
  2. Если доступ ещё не задан, загрузите .cdsapirc / .netrc или вставьте токен. После подключения подготовка продолжится сама. Если доступ уже есть, нажмите «Подготовить и рассчитать».
  3. Приложение установит недостающие библиотеки, найдёт и скачает каналы именно выбранного продукта, запросит ERA5 и проверит файлы. При подключённом RTTOV и известном угле выполнится расчёт; прошедшую проверку шкалу можно применить одной кнопкой.

Закрытие окна не отменяет задачу. Повторное открытие показывает тот же этап. Для остановки используйте «Остановить»: готовые данные сохраняются, незавершённые дочерние процессы останавливаются. После перезапуска сервера нажмите «Продолжить» / «Повторить подготовку»; реквизиты потребуется подключить заново.

Сегодняшний снимок

ERA5T обычно отстаёт приблизительно на пять суток. Для нового срока до загрузки показывается «Выбрать архивный срок»: приложение предлагает дату с запасом в шесть суток и открывает каталог. Это оценка, а не гарантия наличия данных у поставщика. Подстановка другой даты в калибровку текущего снимка запрещена. В подробностях можно явно запросить проверку публикации нового срока.

ECMWF: периодичность обновления ERA5T

Начальная область — 70–76° с. ш., 10–20° в. д., участок Норвежского моря. В «Область, источник и подробности» можно выбрать другой участок. Область должна пересекать снимок; открытая вода и безоблачность здесь не гарантируются. Координаты, список переменных и режимы доступа не требуется настраивать при каждом запуске.

.netrc и .cdsapirc — разные способы доступа

Copernicus CDS: зарегистрируйтесь в CDS, примите условия двух наборов — ERA5 pressure levels и single levels — и получите персональный токен. Стандартный файл .cdsapirc:

url: https://cds.climate.copernicus.eu/api
key: ВАШ_ПЕРСОНАЛЬНЫЙ_ТОКЕН

Токен можно ввести непосредственно в поле пароля интерфейса. Приложение также поддерживает собственный импорт токена из .netrc (сам CDS API такого файла не требует):

machine cds.climate.copernicus.eu login token password ВАШ_ПЕРСОНАЛЬНЫЙ_ТОКЕН

NCAR / GDEX: импортируется обычная запись .netrc соответствующего провайдера:

machine rda.ucar.edu login ВАШ_ЛОГИН password ВАШ_ПАРОЛЬ

Пароль NCAR не передаётся в CDS. Учитываются только разрешённые записи провайдера; default и макросы macdef не принимаются. Сначала GDEX запрашивается публично. При ответе 401 используется только запись точного узла из .netrc; учётные данные rda.ucar.edu не переименовываются автоматически в tds.gdex.ucar.edu. Сессия с cookie живёт в памяти процесса. Если поставщик изменил авторизацию или не объявляет NCSS, будет показана ошибка, не загрузка вымышленного поднабора.

Библиотеки устанавливаются автоматически

Новый установщик включает ERA5 по умолчанию. Для старой установки кнопка подготовки проверяет импорты и, если нужно, создаёт окружение era5/runtime внутри папки состояния. Устанавливаются зависимости из файлов поставки, без sudo, изменения системного Python и выполнения переданных из браузера команд. Расчёт запускается в этом окружении; сервер перезапускать не требуется.

Нужны доступ к PyPI, свободное место и пакет venv используемого Python. Для полностью локальной установки положите совместимые колёса в папку wheelhouse проекта. Если установка прервана или не прошла проверку импорта, этап не становится зелёным. Кнопка «Установить библиотеки сейчас» находится в подробностях и доступна даже для слишком свежего снимка.

Проверка из командной строки
python scripts/setup_era5.py --state-dir /путь/к/папке-состояния

Это тот же установщик, который используется интерфейсом. Флаг --minimal обычного install.py оставляет только просмотр GeoTIFF; последующая подготовка ERA5 всё равно доступна из приложения.

RTTOV устанавливается отдельно один раз

RTTOV предоставляется NWP SAF после регистрации и принятия лицензии. Нужна сборка 13.2 с Python-обёрткой. Приложение не принимает условия лицензии вместо пользователя и не выдаёт pip install pyrttov за установку расчётчика.

Автоматически проверяются уже импортируемая обёртка, путь ARKTIKA_RTTOV_PATH, сохранённая папка и стандартные расположения ./rttov132/wrapper, ~/rttov132/wrapper, /opt/rttov132/wrapper. Если RTTOV не найден, ERA5 всё равно загрузится, а сверху появится действие «Подключить RTTOV». Укажите папку доверенной установленной сборки и нажмите «Проверить и подключить». Сохраняется только путь, не реквизиты.

Таблица rtcoef_electro-l_2_msugs_o3co2.dat загружается автоматически перед расчётом, если её ещё нет. Существующий файл можно указать через ARKTIKA_ELECTROL_COEF. Его контрольная сумма входит в отчёт. Поддерживаемый расчётный интерфейс — RTTOV 13.2; RTTOV 14 требует отдельного адаптера.

Если геометрия неизвестна, после подготовки данных показывается «Указать угол». Угол берётся из геометрии наблюдения, а не из температурного диапазона; значение применяется как явное постоянное приближение для небольшой области. Нулевой угол автоматически не подставляется. Восстановление орбиты и массив углов по пикселям в этой версии не реализованы.

Оба часа, окружающих наблюдение, загружаются отдельно; для 23:30 это 23:00 текущих суток и 00:00 следующих. В точный час второй запрос не нужен. Линия 180° разбивает область на два запроса. Пространственный шаг — 0,25°. Профили выбираются на узлах ERA5, а DN — из однородной окрестности 3×3 исходных пикселей. Масштабы ERA5 и спутниковой выборки не тождественны: независимая оценка репрезентативности остаётся необходимой.

Для всех ИК-каналов используется полный атмосферный оператор, поэтому даже оконному каналу нужны влажность и озон. Канал 4 калибруется только по ночным опорам: высота Солнца ≤ −6°. Солнце не включается в тепловой расчёт коротковолнового канала. В этой версии дневная калибровка канала 4 не реализована.

ERA5T обычно публикуется с задержкой порядка 5 суток; архив GDEX может отставать дольше. Текущий срок не заменяется предыдущими сутками. Кэш недавних данных обновляется через сутки, поскольку ERA5T может изменяться. Завершённые файлы кэша и отчёты сохраняются при отмене.

Проверка и ограничения

Опоры требуют доли суши ≤0,01, льда ≤0,01 и облачности ≤0,01 на обоих часах. Это модельный отбор, а не независимая облачная маска. Высота облака не используется для калибровки того же неизвестного сигнала.

Минимум 24 опоры, четыре пространственные группы и диапазон опорных температур не менее 10 K. Применяется устойчивая линейная регрессия DN→модельная BT. Проверка исключает целые пространственные группы. Порог допуска: групповое RMSE ≤2 K, среднее смещение ≤1 K. Это инженерные критерии опытной версии, не стандарт точности МСУ-ГС/А. При провале порогов коэффициенты не применяются.

Тёплые опоры не калибруют холодные вершины. Даже успешно подобранная шкала действует только внутри фактического диапазона DN опор. Для холодной части нужны дополнительные независимые измерения; здесь такой источник не подключён.

Систематические ошибки ERA5, спектральное отличие Электро-Л, облачная примесь, геометрия и масштаб осреднения не исчезают при малом RMSE. Верх профиля ограничен 1 гПа; выше работает обработка верхней атмосферы RTTOV. CO₂ и другие не загруженные газы берутся из стандартных профилей RTTOV. q на 2 м рассчитывается по точке росы над жидкой водой.

Коэффициенты закрепляются за хешем каждого исходного файла и только выбранным сроком. Подмена/изменение TIFF блокирует повторное применение. Карта, анализ точки и маршрут одинаково исключают выход за диапазон. Отчёт JSON содержит запросы, хеши, коэффициенты, отбор и проверку, но не токены и не частные пути файлов.

В поставку включены реальные табличные спектральные отклики каналов 4–10 из публикации NWP SAF от 26 ноября 2019 года (источник PLANETA, Andrei Filei). Они хранятся отдельно от коэффициентов RTTOV. Центры полос вычисляются из этих таблиц; данные не получены подгонкой изображений.
