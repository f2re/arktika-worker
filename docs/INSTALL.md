# 💻 Установка и развёртывание

Пошаговое руководство по установке и запуску рабочего места метеоролога «Арктика-М».

---

## 📋 Системные требования

* **Операционная система:** Windows 10/11, современные дистрибутивы Linux (Ubuntu 22.04+, Debian 12+, Astra Linux и др.), macOS 12+.
* **Python:** версия **3.10** или новее (рекомендуются 3.11 или 3.12).
* **Браузер:** любой современный браузер (Chrome, Edge, Firefox, Яндекс.Браузер, Safari) с поддержкой SVG и современных веб-стандартов.
* **Ресурсы:** от 4 ядер CPU, от 8 ГБ RAM, свободное место на диске для спутникового архива.
* **Внешние серверы и GPU:** **не требуются**. Docker, Node.js, СУБД и видеокарты не нужны — всё считает один локальный процесс Python.

---

## 🪟 Быстрый старт на Windows

1. Убедитесь, что установлен [Python 3.10+](https://www.python.org/downloads/windows/). При установке обязательно отметьте галочки **«Add python.exe to PATH»** и **«Install launcher for all users (py)»**.
2. Распакуйте архив с проектом в удобную папку (например, `C:\Apps\arktika-worker`).
3. Запустите файл **`install.cmd`** двойным щелчком мыши:
   * Скрипт создаст изолированное виртуальное окружение `.venv` и установит необходимые библиотеки.
   * Права администратора **не требуются**.
4. После завершения установки запустите **`start.cmd`**.
5. Браузер откроет страницу приложения автоматически: `http://127.0.0.1:8765/#ключ-сессии`.

---

## 🐧 Быстрый старт на Linux и macOS

Откройте терминал в папке проекта и выполните две команды:

```bash
# 1. Установка окружения и зависимостей
sh install.sh

# 2. Запуск системы
sh start.sh
```

Сервер напечатает адрес вида `http://127.0.0.1:8765/#ключ_сессии` и автоматически откроет вкладку в браузере.

> [!TIP]
> **Минимальная установка:** если вам нужен только базовый просмотр и анализ локальных GeoTIFF без библиотек реанализа (xarray, netCDF4, cdsapi), запустите установку с ключом `--minimal`:
> ```bash
> python3 install.py --minimal
> ```

## ⚙️ Полезные параметры запуска

Сервер можно запускать с дополнительными аргументами командной строки:

```bash
# Свой порт и отдельные папки для данных и загрузок
.venv/bin/python server.py --port 8765 --data-dir ./data --download-dir /srv/arktika/downloads

# Запуск на сервере без автоматического открытия графического браузера
.venv/bin/python server.py --no-browser

# Автоматический импорт существующей папки со снимками GeoTIFF при старте
.venv/bin/python server.py --import-local /path/to/Arktika-M-Archive

# Использование токена из защищённого файла
.venv/bin/python server.py --token-file /etc/arktika/gptl.token
```

## 🌐 Работа на удалённом сервере через SSH

Сервер из соображений безопасности привязан **строго к локальному интерфейсу 127.0.0.1**.

Для работы на удалённом сервере без графической оболочки пробросьте порт через SSH-туннель:

```bash
ssh -L 8765:127.0.0.1:8765 user@remote-server
```

Затем запустите приложение на сервере (`sh start.sh`) и откройте напечатанную ссылку на вашем локальном компьютере.

## 📦 Офлайн-установка (без доступа к интернету)

Для закрытых контуров подготовьте бинарные пакеты на компьютере с доступом в сеть (с той же ОС, архитектурой и версией Python):

```bash
python -m pip download --only-binary=:all: -r requirements.txt -r requirements-era5.txt -d wheelhouse
```

Перенесите папку `wheelhouse` и проект на целевую машину и установите:

```bash
python install.py --wheelhouse wheelhouse
```

---

## 🔄 Обновление версии

1. Остановите работающий сервер (`Ctrl + C` в консоли).
2. Сохраните резервную копию папки состояния `data/` и папки загрузок.
3. Обновите файлы проекта.
4. Выполните скрипт установки `install.cmd` / `sh install.sh`.
5. Запустите приложение. Вся база локальных снимков и настроек сохранится!
