# Проверка рабочего места ПМЦ на реальном ERA5

## Исходные данные

Используется реанализ **ERA5 ECMWF**, опубликованный проектом Google Research **ARCO ERA5** в открытом хранилище. Это исторический анализ на регулярной сетке 0,25°, подготовленной владельцами ARCO ERA5 из ERA5. Он не является прогнозом или результатом генератора тестовых полей.

- Срок: **1 января 2020 года, 00:00 UTC**.
- Область исходного фрагмента: **60–85° с. ш., 25° з. д. — 70° в. д.**
- Проекция приёмочного расчёта: пресет `barents`, EPSG:3995, ширина 512 ячеек.
- Поля: ветер 850 гПа, давление на уровне моря, ветер 10 м, температура 500 гПа, температура поверхности моря, концентрация морского льда, доля суши.
- Источник и описание подготовки: [Google Research / ARCO ERA5](https://github.com/google-research/arco-era5).
- Набор: `gs://gcp-public-data-arco-era5/ar/full_37-1h-0p25deg-chunk-1.zarr-v3`.

Скрипт получает конкретные объекты публичного хранилища по HTTPS, проверяет время и координаты, выбирает нужные уровни и прямоугольный фрагмент. Значения не заменяются искусственными, пропуски не заполняются. Упаковка в локальный NetCDF и необходимые изменения имён/единиц метаданных перечисляются в `provenance.json`; исходные URL и SHA-256 позволяют проверить происхождение байтов. Пользовательские ключи CDS/Earthdata не используются.

Глобальные часовые блоки источника крупнее конечного фрагмента: пакет с дополнительным геопотенциалом требует около 397 MiB сетевой загрузки. Исходные массивы и рабочие базы не включаются в Git. После загрузки скрипт пишет `wind850.nc`, `surface.nc`, `t500.nc`, `profile.json` и `provenance.json` в выбранный каталог.

`profile.json` содержит настоящий вертикальный профиль того же срока в узле 70° с. ш., 30° в. д. Температура, давление и геопотенциал берутся из исходного реанализа. Сначала вычисляется геопотенциальная высота `h = Φ / 9.80665`, затем приближённая геометрическая высота `z = R h / (R − h)`, где `R = 6 371 229 м`. Это [сферическое приближение ECMWF](https://confluence.ecmwf.int/spaces/CKB/pages/158636068/ERA5%2Bcompute%2Bpressure%2Band%2Bgeopotential%2Bon%2Bmodel%2Blevels%2Bgeopotential%2Bheight%2Band%2Bgeometric%2Bheight), без горизонтальных вариаций ускорения тяжести; оно явно обозначено в источнике и примечании профиля. Профиль используется для отдельной проверки импорта и выбора; под дату спутниковой сцены он не переносится.

## Воспроизведение

Установите зависимости приложения и `numcodecs==0.17.1`. Получение реального пакета:

```bash
python scripts/fetch_pmc_real_case.py --output /absolute/path/pmc-era5-real
```

Проверка импорта и расчёта без браузера:

```bash
python scripts/pmc_workspace_browser_smoke.py \
  --input-netcdf /absolute/path/pmc-era5-real/wind850.nc \
  --pressure-netcdf /absolute/path/pmc-era5-real/surface.nc \
  --field t500=/absolute/path/pmc-era5-real/t500.nc \
  --field wind10=/absolute/path/pmc-era5-real/surface.nc \
  --field sst=/absolute/path/pmc-era5-real/surface.nc \
  --field ice=/absolute/path/pmc-era5-real/surface.nc \
  --field lsm=/absolute/path/pmc-era5-real/surface.nc \
  --source era5 --time 2020-01-01T00:00:00Z --area 85 -25 60 70 --preset barents \
  --provenance /absolute/path/pmc-era5-real/provenance.json \
  --numerical-only --output browser-results/pmc-numerical
```

Для полного браузерного сценария установите Playwright/Chromium и выполните ту же команду без `--numerical-only`. Обязательны реальный входной файл и паспорт происхождения; генератор данных при отсутствии файла не запускается. В CI обе стадии — получение ERA5 и браузерная проверка — выполняются последовательно.

## Что проверяет сценарий

Штатный импорт каждого из семи полей, нормализацию, вычисление завихрённости и кандидатов при исходных порогах, автоматическую наноску, отображение ветра и изобар, ручную пометку, загрузку настоящего PNG, серверную закладку и восстановление после перезагрузки приложения. Пустой результат детектора допустим: ради изображения пороги не изменяются и кандидат не добавляется в результат вычислений вручную.

Локальный численный прогон импортировал все семь полей и выделил **9 кандидатов** на исходных порогах. Все девять имеют статус `not_confirmed` и действительную геометрию пороговых областей. Итоговая ручная пометка остаётся кандидатом без экспертного подтверждения. Поля, источник и UTC на карте относятся к реальному анализу. PNG и машинный отчёт находятся в артефакте `browser-results` соответствующего запуска GitHub Actions.

Это проверка работоспособности на настоящем реанализе. Срок не выбран как независимо подтверждённый случай ПМЦ; полученные вихревые кандидаты требуют сопоставления с наблюдениями. Из него нельзя вычислить статистическую вероятность обнаружения, пропуски или ложные тревоги. Для такой оценки нужна независимая размеченная выборка событий.
