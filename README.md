**Локальный программный комплекс для оперативной работы метеоролога** со спутниковыми данными космических аппаратов **«Арктика-М»** (прибор МСУ-ГС), атмосферными реанализами (**ERA5**, **CARRA2**, **MERRA-2**), вертикальными профилями радиозондирования и авиационными маршрутами.

> [!NOTE]
> **Архитектурная чистота:** один процесс Python, встроенная база SQLite и браузер. Никаких внешних картографических сервисов, CDN, Docker, Node.js, GPU или облачных баз данных. Полная независимость от сети при работе с локальными файлами.

## 🚀 Быстрый запуск за 3 шага

Нужен **Python 3.10+** (рекомендуются 3.11 или 3.12).

### 🪟 Windows
1. Скачайте и распакуйте репозиторий.
2. Дважды кликните **`install.cmd`** (создаст изолированное окружение `.venv` и установит зависимости; права администратора не нужны).
3. Запустите **`start.cmd`** — браузер откроется автоматически!

### 🐧 Linux / 🍏 macOS
```bash
# Шаг 1. Установка в локальное изолированное окружение .venv
sh install.sh

# Шаг 2. Запуск локального сервера
sh start.sh
```
После старта откройте напечатанный сервером безопасный локальный адрес:
`http://127.0.0.1:8765/#ваш-ключ-сессии`

## 🔑 Авторизация и токены: откуда копировать и куда вставлять

### 1. Геопортал Роскосмоса (GPTL / «Арктика-М»)
> Нужен для поиска по официальному каталогу и скачивания свежих GeoTIFF-снимков.

```
┌────────────────────────────────────────────────────────────────────────┐
│ Браузер: geoportal.gptl.ru                                             │
│ 1. Войдите в учётную запись                                            │
│ 2. Нажмите F12 → Вкладка «Network» (Сеть) → фильтр «Fetch/XHR»         │
│ 3. Кликните по любому разделу каталога                                 │
│ 4. Request Headers → Authorization: Bearer eyJhbGciOi...               │
│                                            └─── Скопируйте токен       │
└────────────────────────────────────┬───────────────────────────────────┘
                                     │ Вставьте
                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│ В приложении «Арктика-М»:                                              │
│ Значок 🔑 в верхнем правом углу → GPTL → [ Подключить ]                │
└────────────────────────────────────────────────────────────────────────┘
```

1. **Откройте [geoportal.gptl.ru](https://geoportal.gptl.ru/)** и авторизуйтесь под своим логином.
2. **Откройте панель разработчика (DevTools):** нажмите `F12` (или `Ctrl+Shift+I` в Windows/Linux, `Cmd+Opt+I` на macOS) ➔ перейдите на вкладку **«Сеть» (Network)**.
3. **Включите фильтр «Fetch/XHR»** и обновите страницу (или кликните по каталогу).
4. **Найдите любой сетевой запрос** к `api.gptl.ru` или `geoportal.gptl.ru` (например, `search`, `catalogs`, `profile`).
5. **В блоке «Заголовки запроса» (Request Headers)** найдите строку `Authorization: Bearer eyJ...`.
6. **Скопируйте токен** (строка, начинающаяся с `eyJ...`). Приложение принимает как чистый токен, так и строку с префиксом `Bearer `.
7. **Вставьте в приложение:** нажмите кнопку с ключом **🔑 (Источники данных)** в правом верхнем углу ➔ «Арктика-М / GPTL» ➔ вставьте токен ➔ нажмите **«Подключить»**.

---

### 2. Copernicus CDS (ERA5 и CARRA2)
> Нужен для загрузки полей реанализа ERA5 / CARRA2 и калибровки шкал.

1. Зарегистрируйтесь / войдите на портале [cds.climate.copernicus.eu](https://cds.climate.copernicus.eu/).
2. Перейдите на страницу инструкции [How to use the CDS API](https://cds.climate.copernicus.eu/how-to-api) (или в свой профиль) и скопируйте **Personal Access Token (PAT)**.
3. Примите условия использования (Terms of Use) для набора данных [ERA5 hourly pressure levels](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-pressure-levels) (один раз).
4. В приложении: нажмите **🔑** ➔ **Copernicus CDS** ➔ вставьте токен (или выберите файл `.cdsapirc`) ➔ **«Сохранить в памяти»**.

---

### 3. NASA Earthdata (MERRA-2)
> Нужен для атмосферного реанализа MERRA-2 через NASA GES DISC.

1. Зарегистрируйтесь на [urs.earthdata.nasa.gov](https://urs.earthdata.nasa.gov/).
2. В личном кабинете в разделе «Applications» ➔ «Authorized Apps» разрешите доступ приложению «NASA GES DISC DATA ARCHIVE».
3. В разделе «Applications» ➔ «Generate Token» скопируйте User Token.
4. В приложении: нажмите **🔑** ➔ **NASA Earthdata** ➔ вставьте токен ➔ **«Сохранить в памяти»**.

---

### 4. Локальный режим без интернета
> 💡 **Интернет и токены НЕ нужны**, если у вас уже есть файлы снимков GeoTIFF!

Просто нажмите кнопку **«Открыть GeoTIFF»** в панели снимков слева и укажите локальную папку со снимками. Приложение мгновенно проиндексирует сцены без перемещения файлов.

## 🛰️ Как пользоваться системой

### Шаг 1. Открыть или скачать снимок
* **Есть файлы на компьютере:** нажмите `Открыть GeoTIFF` в панели слева ➔ выберите папку. Дни с локальными данными подсветятся в календаре кружками.
* **Скачивание из сети:** при активном токене выберите дату ➔ `Найти снимки` ➔ у нужного срока нажмите `Каналы и файлы` ➔ отметьте галочками нужные каналы ➔ `Скачать выбранное`. Загрузка пойдет в фоновую очередь (иконка ⬇️ слева).

### Шаг 2. Выбрать задачу и продукт (RGB / ИК)
Перейдите на вкладку **«Продукты»** на панели слева:
* 🌤️ **Облачность (RGB):** круглосуточная микрофизика, визуализация фронтальных систем.
* 🌫️ **Низкие облака / туман:** ночная микрофизика (разность 3.8 и 10.8 мкм).
* 🌡️ **Оконный ИК (Канал 9):** яркостная температура $T_я$ облаков и поверхности.
* 🌀 **Водяной пар (Каналы 7 и 8):** тропосферные струйные течения и высотная влажность.
* ❄️ **Фаза облачности:** совместные спектральные кандидаты капельной и ледяной фаз.
* 🌐 **Поля реанализа:** изобарические карты температуры, геопотенциала, влажности и ветра.

Нажмите **«Показать на карте»**. Для чтения оттенков нажмите кнопку легенды **ℹ️** в заголовке карты.

### Шаг 3. Анализ точки на карте
Кликните по любой точке облачности на карте. В панели **«Анализ»** справа отобразятся:
* Точные географические координаты.
* Яркостная температура $T_я$ и спектральные разности ($T_{10.8}-T_{12.0}$, $T_{3.8}-T_{10.8}$).
* Карточки физической интерпретации структуры облачности.

### Шаг 4. Профиль атмосферы и высота облака
1. Нажмите кнопку **«Профиль»** в верхней панели и загрузите CSV/JSON радиозондирования или численной модели погоды ([шаблон CSV](docs/profile-template.csv)).
2. В инспекторе точки выберите профиль, подтвердите облачность и нажмите **«Пересчитать с профилем»**.
3. Система найдет пересечения $T(z) = T_я$ и отобразит высоту ВГО, чувствительность к $\pm \Delta T$ и оценку жидкой воды в слое.

### Шаг 5. Построение маршрута полета
1. Вкладка **«Маршрут»** слева ➔ кнопка **«Нарисовать»** ➔ расставьте путевые точки на карте ➔ **«Готово»**.
2. Задайте время вылета (UTC), скорость (км/ч) и шаг выборки (км).
3. Нажмите **«Проанализировать маршрут»** — система построит профиль сигнала вдоль трассы и покажет расчетные условия прохождения.

### Шаг 6. Экспорт результатов
* **Экспорт геопродукта:** синяя кнопка с иконкой загрузки ⬇️ в шапке окна выгружает архив: полноразмерный растр PNG с легендой, геопривязанный GeoTIFF и JSON происхождения данных.
* **Экспорт маршрута:** выгрузка в CSV и GeoJSON на вкладке маршрута.
* **Экспорт паспорта точки:** кнопка «Сохранить анализ» в инспекторе.

## 🛡️ Безопасность и метеорологические принципы

1. **Строгая локальность:** сервер слушает исключительно `127.0.0.1`. Доступ извне блокируется встроенной защитой origin/cookie/session.
2. **Токены только в памяти:** access и refresh токены хранятся исключительно в RAM и исчезают при выходе.
3. **Физическая строгость:**
   * Сырые DN-значения прибора не равны кельвинам без объявленной калибровки. Допущение `DN=K` включается только оператором и явно маркируется в экспорте.
   * Спутниковая яркостная температура вершины облака $T_я$ не равна температуре воздуха на эшелоне полета.
   * Спектральная фаза на вершине не гарантирует условия обледенения внутри облачного слоя.
