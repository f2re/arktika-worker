# История изменений

## 0.2.0 — 23.09.2026

- Карта как основной экран; тональные компоненты, SVG-пиктограммы, контекстные панели, адаптация для узкого экрана и клавиатурные подсказки.
- Лента сроков, автоматический пересчёт продукта, сохранение вида и защита от устаревшего ответа вычислителя.
- Четыре спектральные разности, объяснимые гипотезы в точке, отдельный георастр кандидатов фазы.
- Тематические цветовые легенды с практическим смыслом, включённые в экспорт.
- CSV/JSON-профили с проверкой места/времени/единиц; график T(z), многозначная высота, чувствительность, температура и жидкий конденсат в слое.
- Маршрутные узлы: перетаскивание/редактирование, геодезическая линия, профильные условия по ETA, новые поля CSV/GeoJSON.
- 126 автоматических проверок; версия тестового отчёта — docs/VERIFICATION.md.

# Изменения

## 0.1.0 — 22.09.2026

Начальная ГИС-поставка для репозитория arktika-worker. Повторно использован сетевой слой прежнего веб-загрузчика: STAC, STS, S3, кэш и очередь. Добавлены реестр физических каналов, калибровочный барьер, единая картографическая сетка, локальные сцены, научно ограниченный цветосинтез, интегральные признаки, анализ пикселя и маршрута, профильная лаборатория и экспериментальное слежение.

Новый интерфейс без внешних карт и CDN. Экспорт с легендой, кодом качества, происхождением и автономным отчётом. Подготовлены документация, план расширения, тесты и отдельный безопасный сценарий публикации через Git.

Публикация этой поставки в удалённый GitHub не является частью выполненных локальных тестов. Результат push должен проверяться отдельно.
