Подключение GPTL

Токены хранятся только в памяти сервера. Внешние изображения открываются публично, когда это разрешено; Bearer используется для каталога и STS.

Получение и обновление через OAuth

Нужен client_id, зарегистрированный оператором GPTL для этого приложения. Одного Bearer недостаточно для обновления.

Секрет конфиденциального клиента — только переменная GPTL_CLIENT_SECRET на сервере. Поддержку PKCE должен разрешить оператор.

Калибровка и единицы

UInt16 и имя L2IR не доказывают шкалу в кельвинах. Неподтверждённая температура всегда помечается как допущение.

Уже созданные продукты сохраняют прежнюю калибровку и легенду.
