# Безопасность

Модель угроз MVP: один доверенный оператор на своём компьютере. Сервер — только loopback. Приложение не является защищённым многопользовательским геопорталом и не должно публиковаться на 0.0.0.0 или через общедоступный reverse proxy.

Отчёты об уязвимостях направлять владельцу репозитория приватным каналом. Не прикладывать токен, подписанный URL, дамп локальной базы или ключ запуска к публичному issue. Если GitHub private vulnerability reporting включён владельцем, использовать его; наличие этой функции в репозитории не предполагается автоматически.

Реализованы TLS без отключения проверки, allowlist хостов GPTL, запрет переноса Bearer на сторонние хосты, cookie локальной сессии, проверка Host/Origin, защита POST, ограничения тела запроса и HTTP-параллелизма. Сетевые URI не передаются напрямую GDAL. Исходные пути выбирает пользователь, API не открыто анонимным веб-страницам.

OAuth: state с коротким сроком и однократным использованием, PKCE S256, code exchange на сервере. Access/refresh/STС-секреты не сохраняются. Secret клиента при необходимости поступает из окружения.

Ограничения: доверенные пользователи одной ОС могут читать доступные им файлы и окружение; это не контейнерная изоляция. Не открывать произвольные повреждённые растры из недоверенных источников: Rasterio/GDAL — нативный стек. Нужны обновления зависимостей, резервирование данных и контроль диска. Ограничение размера исходных TIFF и внешняя песочница остаются задачами следующей версии.
