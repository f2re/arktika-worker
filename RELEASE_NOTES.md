# Арктика-М 0.3.0 — поля реанализа и многослойная карта

Первый GitHub Release рабочего места с самостоятельным сценарием ERA5, CARRA2 и MERRA-2. Спутниковый просмотр и калибровка остаются отдельными задачами.

## Новое

«Источники данных → Добавить поле» и «Слои → ＋»: выбор источника, величины, уровня, точного срока UTC и области без обязательного спутникового снимка или RTTOV. Настройка CDS/Earthdata доступна из окна поля с возвратом к выбранным параметрам.

Загрузка через CDS, поиск объявленных файлов MERRA-2 через NASA CMR и выборка OPeNDAP; проверяемый локальный кэш и импорт NetCDF/GRIB. До восьми полей поверх спутника: заливка, изолинии, стрелки географического ветра, непрозрачность, порядок и видимость. Состав карты сохраняется.

Совместный инспектор исходных значений и разности A − B при совпадении величины, уровня, времени, единиц и временной семантики. Разность на более грубой исходной сетке с общей маской; перепроецирование не повышает разрешение. Экспорт CF-NetCDF и JSON с происхождением данных.

## Исправления относительно PR №11

Поверхностные поля MERRA-2 запрашиваются из мгновенной часовой коллекции M2I1NXASM, не из часовых средних. Анализы CARRA2 не заменяются промежуточными прогнозами; текущие параметры и опубликованные годы сверяются со схемой CDS. Усилены проверки единиц, времени, уровней, пропусков, версий файлов и перенаправлений HTTPS.

Независимые реквизиты CDS сохраняются в памяти при переключении экспериментальной ERA5-калибровки на GDEX. Минимальные версии библиотек и исправления независимого выбора области из main сохранены. Версия приложения, API и манифеста согласована.

## Установка и обновление

Распакуйте `arktika-worker-v0.3.0.zip` в отдельную папку. Linux/macOS: `sh install.sh`, затем `sh start.sh`. Windows: `install.cmd`, затем `start.cmd`. Нужен Python 3.10+; матрица CI использует 3.11/3.12. Архив содержит исходники и установочные скрипты, а не автономную поставку Python и зависимостей. Для локального GRIB дополнительно установите `requirements-grib.txt` в окружение приложения.

Перед обновлением остановите сервер и сохраните резервную копию папки состояния. Спутниковые исходники не перемещаются. Укажите прежний `--data-dir` для продолжения работы с каталогом. Не запускайте две версии с одной базой.

Кэш полей раннего PR №11 физически сохраняется, но автоматически не переиспользуется: изменились формат метаданных и временная семантика MERRA-2. Получите эти поля повторно либо сохраните старые экспорты отдельно. Новый кэш и новый стек восстанавливаются после перезапуска. Секреты остаются только в памяти процесса и вводятся заново после остановки сервера.

## Проверка и ограничения

Публикация релиза разрешена только после успешного прохождения всей матрицы Python, установки расширенного окружения, браузерных сценариев, проверки коэффициентов и сборки архива. `build-info.json` содержит точный коммит и контрольные суммы; журнал CI доступен на вкладке Actions.

Тестовые поля синтетические и проверяют программные контракты. Живой вход и скачивание от имени пользователя CDS/Earthdata, а также независимая метеорологическая верификация не выполнялись. Доступность конкретных дат зависит от источника и принятых пользователем условий.

Детальная береговая линия, тайлы и автоматические пространственные профили вдоль маршрута не входят в этот релиз. CARRA2 не получает вымышленные компоненты ветра при отсутствии подтверждённого направления. Кандидат вращения спутникового рисунка не объявляется подтверждённым ПМЦ.
